The SVG brand marks in this folder were sourced from the Simple Icons project and stored locally so the portfolio does not fetch them from a third-party CDN at runtime. Some employer and credential issuers do not have an available icon in that collection; the site uses a compact initials mark for those entries.

Simple Icons project: https://github.com/simple-icons/simple-icons

Each brand mark remains subject to its owner’s trademark and brand-use guidance. The icons are shown only to identify employers and credential issuers in Alaeddine Najjar’s professional history.
